# Parte 1 — Exercícios de lógica e orientação a objetos inicial com Dart

Na Parte 1, comecei estudando os fundamentos da programação usando Dart. Trabalhei inicialmente com variáveis, tipos básicos (`String`, `int`, `double`, `bool`) e saída de dados utilizando `print()` e interpolação de strings.

Depois avancei para estruturas condicionais (`if`, `else if`, `else`) criando programas que calculavam médias de alunos e verificavam situações como aprovação, recuperação e reprovação.

Também pratiquei a criação de funções com retorno (`bool`, `int`, `double`) para resolver problemas de lógica, como:
- verificar se um número é par,
- descobrir o maior entre três números,
- somar elementos de listas,
- calcular médias,
- buscar nomes em listas,
- contar alunos aprovados.

Em seguida, comecei a trabalhar com coleções no Dart, utilizando:
- `List`
- `Map`

Com listas, percorri dados usando `for in`, filtrei números positivos, apliquei descontos em preços e trabalhei com listas de nomes.

Com mapas (`Map`), representei dados de alunos utilizando pares `chave: valor`, acessando informações como nome, matrícula, curso e nota final.

Após isso, iniciei meus estudos em programação orientada a objetos (POO). Aprendi a:
- criar classes,
- definir atributos,
- criar construtores,
- instanciar objetos,
- criar métodos.

Desenvolvi várias classes, como:
- `Aluno`
- `Produto`
- `ContaBancaria`
- `Tarefa`
- `Pedido`

Na classe `Aluno`, implementei métodos para verificar aprovação automaticamente com base na nota final.

Na classe `Produto`, criei um método para calcular o valor total em estoque utilizando preço e quantidade.

Na classe `ContaBancaria`, desenvolvi funcionalidades de:
- depósito,
- saque,
- exibição de saldo,
- validação de saldo insuficiente.

Na classe `Tarefa`, trabalhei com alteração de estado dos objetos usando um método para marcar tarefas como concluídas.

Também comecei a trabalhar com listas de objetos, percorrendo listas de `Tarefa` e filtrando apenas tarefas pendentes.

Além disso, criei funções que manipulavam listas de objetos, como encontrar o pedido de maior valor em uma lista de pedidos.

Para finalizar a Parte 1, desenvolvi um pequeno sistema completo de gerenciamento de alunos utilizando:
- classes,
- listas,
- funções,
- métodos,
- filtros,
- cadastro de alunos,
- listagem de aprovados.

Durante essa etapa, aprendi conceitos importantes como:
- lógica de programação,
- reutilização de código,
- manipulação de listas,
- filtragem de dados,
- orientação a objetos,
- encapsulamento básico de comportamento em métodos,
- organização de código.

Essa primeira parte construiu minha base em Dart e programação orientada a objetos, preparando o caminho para conteúdos mais avançados como coleções avançadas, programação funcional, Flutter e integração com Firebase.
